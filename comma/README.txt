- 재생 버튼으로 자동 전환 시작: 1 / 5 → 2 / 5
- 일시정지 후 6500ms 경과: 2 / 5 유지
- 마지막 화면 → 다음: 1 / 5
- 첫 화면 → 이전: 5 / 5
- Home 후 ArrowRight: 2 / 5
- 표시 중인 설명과 이미지 각각 1개, 나머지 4개는 hidden
- 첫 배지·마지막 배지의 중앙 오차 0px (측정한 브라우저 환경 기준)
- 선택된 aria-pressed 상태 1개
- 390px 모바일에서 마지막 배지 중앙 오차 0px, 선택 상태 1개
- 390px 모바일 슬라이드 단일 열, 제어 버튼 영역 가로 넘침 없음
